# Planilha de FIIs em Excel

Este repositório contém uma planilha desenvolvida em Excel para controle e análise de Fundos de Investimento Imobiliário (FIIs).

## Objetivo
Organizar e acompanhar informações sobre FIIs, como:
- Nome do fundo
- Salário
- Valor investido
- Dividendos
- Rentabilidade
- Perfil do investidor

## Ferramentas utilizadas
- Microsoft Excel

## Observações
Projeto desenvolvido como atividade prática em curso de Excel.
